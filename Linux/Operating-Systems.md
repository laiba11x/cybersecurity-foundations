# Operating Systems – Introduction

## What is an Operating System?

An **Operating System (OS)** is the main software that manages a computer's **hardware, applications and resources**.

Examples:

* Windows
* Linux
* macOS

The OS acts as a **middle layer between the user, applications and hardware**.

## Kernel Space & User Space

### Kernel Space

* The highly privileged part of the OS.
* The **kernel** runs here.
* Has direct and unrestricted access to hardware such as the CPU, RAM and storage.

### User Space

* Where normal applications run.
* Applications have limited permissions.
* They use **system calls** to ask the kernel to perform tasks.

This separation helps improve **security and system stability**.

## Main Duties of an OS

* **Process Management:** Manages running programs and CPU time.
* **Memory Management:** Allocates and manages RAM for applications.
* **File System Management:** Organises files and folders and manages permissions.
* **User Management:** Manages user accounts, authentication and permissions.
* **Device Management:** Manages hardware such as keyboards, mice and printers.

## OS Security

An operating system provides basic security through:

* **Authentication:** Verifies who the user is.
* **Permissions:** Controls what users and applications can access.
* **Isolation:** Keeps processes separated from each other.
* **System Protection:** Protects important system files and settings.

## OS Interfaces

### GUI – Graphical User Interface

A visual way of interacting with an OS using **windows, icons, buttons and menus**.

Example: Clicking a folder to open it.

### CLI – Command-Line Interface

A text-based way of interacting with an OS by **typing commands**.

CLI provides more **control, precision and speed** and is commonly used for technical and cybersecurity tasks.

**GUI = click**

**CLI = type commands**

## Types of Operating Systems

### Desktop

Used for personal computers and everyday tasks.

Examples:

* Windows
* macOS
* Linux

### Server

Used for websites, databases, cloud services and back-end systems.

Common characteristics:

* High reliability
* High uptime
* Multiple users
* Remote access

### Mobile

Used on smartphones and tablets.

Examples:

* Android
* iOS

### Embedded

Used in specialised devices such as:

* Cars
* Routers
* Smart TVs
* IoT devices

### Virtual/Cloud

Used for virtual machines, containers and cloud environments.

## Common Operating System Families

* **Windows:** Widely used on personal computers and business systems.
* **macOS:** Apple's desktop operating system.
* **Linux:** A family of open-source operating systems called **distributions (distros)**.
* **Android:** Mobile operating system used on phones and tablets.
* **iOS:** Apple's mobile operating system.

Examples of Linux distributions include **Ubuntu, Debian and Fedora**.

## Why Are There Different Operating Systems?

Different devices have different requirements.

* **Desktop:** User-friendly and supports multitasking.
* **Server:** Needs reliability, security and high uptime.
* **Mobile:** Needs to be power efficient.
* **Embedded:** Needs to be lightweight and designed for a specific purpose.
* **Cloud/Virtual:** Needs to be scalable and easy to deploy.

There is no single OS that is perfect for every situation.

## Key Takeaways

* An **OS manages hardware, applications and system resources**.
* **Kernel space** has unrestricted hardware access.
* **User space** is where normal applications run.
* **GUI** uses visual elements such as icons and windows.
* **CLI** uses text commands.
* Operating systems have different types because different devices and environments have different requirements.
* **Linux is a family of open-source operating systems**, and Ubuntu is one of its distributions.
