# Product and Tool Documentation

## Official Documentation

Security tools and platforms provide **official documentation** explaining how to use them.

Official documentation is usually the **most reliable and up-to-date source**.

It should be the **first place to check** when:

* Learning how to use a tool
* Troubleshooting unexpected behaviour
* Finding out how to use a feature or command

## Linux Man Pages

**Man pages (manual pages)** are built-in documentation for Linux commands and many cybersecurity tools.

They can be viewed directly from the terminal.

### Command

```bash
man <command>
```

Example:

```bash
man nc
```

This displays the manual page for the `nc` (Netcat) command, including information about its usage and available options.

## Key takeaway

**Official documentation = reliable information about a tool.**

**Man pages = built-in Linux documentation that can be accessed from the terminal.**
