# Cloud Computing

Cloud computing means using computing resources such as servers, storage and applications **over the internet** instead of relying only on your own computer.

## Cloud Types

* **Public Cloud:** Cloud services shared by many users and organisations.
* **Private Cloud:** A cloud environment used by one organisation, giving it more control.
* **Hybrid Cloud:** A combination of public and private cloud.

## Cloud Service Models

* **IaaS (Infrastructure as a Service):** Rent virtual computers, servers, storage and networking. I manage the operating system and applications.
* **PaaS (Platform as a Service):** The provider manages the infrastructure and operating system, allowing me to focus on building my application.
* **SaaS (Software as a Service):** A complete application that I use over the internet, such as Gmail or Zoom.

## EC2

**EC2 (Elastic Compute Cloud)** provides virtual computers in the cloud.

An EC2 instance is basically a **virtual computer/server** that can run applications.

Larger instance types provide more CPU and RAM but cost more.

## Cloud Benefits

* **Scalability:** Handle increases or decreases in users and traffic.
* **On-demand self-service:** Create or remove resources whenever needed.
* **Pay only for what you use:** Costs are based on usage.
* **Security:** Cloud providers protect their infrastructure.
* **High availability:** Applications can continue running if part of the system fails.
* **Global access:** Resources can be accessed from different locations around the world.

## Key Takeaway

Cloud computing makes computing resources **flexible, scalable, cost-effective and accessible over the internet**.
