# VirusTotal

## What is VirusTotal?

VirusTotal is a security service that checks **files, URLs, domains and file hashes** against many antivirus engines and website scanners.

It combines the results into one place to help determine whether something is **malicious or suspicious**.

### How it is used

* Submit a **file**
* Submit a **URL**
* Submit a **domain**
* Search using a **file hash**
* Review which security vendors have flagged it as dangerous

### Why is it useful?

VirusTotal is useful for **blue teaming** and **threat intelligence**.

Security professionals can use it to:

* Investigate suspicious files and links
* Get a general consensus from multiple security vendors
* Gather information about new threats

### Important

VirusTotal is **not foolproof**. A file not being detected does not automatically mean it is safe.

## Key takeaway

**VirusTotal = a tool that combines results from many security vendors to help identify suspicious or malicious files and links.**
