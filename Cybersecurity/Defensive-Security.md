# Defensive Security

## What is Defensive Security?

**Defensive security** focuses on protecting systems from attacks by:

* Preventing attacks.
* Detecting suspicious activity.
* Reducing the impact of attacks.
* Responding to security incidents.
* Keeping systems available and protected.

Defenders are often called the **Blue Team**.

## What Do Defenders Do?

Defenders need to:

* Understand what needs to be protected.
* Gain visibility into systems and networks.
* Identify weaknesses.
* Understand how attackers think and operate.
* Detect and respond to attacks.
* Protect sensitive systems and data.

## CIA Triad

Defensive security supports the three goals of the **CIA Triad**:

* **Confidentiality** — protect information from unauthorised access.
* **Integrity** — prevent unauthorised changes to information.
* **Availability** — keep systems and data accessible when needed.

## Blue Team vs Red Team

* 🔴 **Red Team** — thinks like an attacker and tests security by attempting to exploit weaknesses.
* 🔵 **Blue Team** — defends systems by preventing, detecting and responding to attacks.

### Key Takeaway

**Defensive security = protect, detect, respond.**

Defenders need to understand attackers and their techniques so they can build stronger security and respond effectively when attacks occur.

## What Defenders Protect

Before protecting a system, defenders need to understand **what exists and how everything connects**.

### Common Infrastructure

| Component        | Purpose                                               |
| ---------------- | ----------------------------------------------------- |
| Employee Devices | Devices used by employees to access company resources |
| Web Server       | Hosts websites and applications                       |
| Mail Server      | Sends and receives organisational email               |
| Firewall         | Controls traffic entering and leaving the network     |
| Internet         | External networks outside the organisation's control  |

## Defensive Security Concepts

Defenders generally work through five key areas:

* **Prevention** — security controls that stop attacks, such as firewalls, antivirus and regular patching.
* **Detection** — monitoring systems for suspicious activity using logs, alerts and security tools.
* **Mitigation** — limiting damage during an incident, such as blocking traffic or isolating systems.
* **Analysis** — investigating what happened, how it happened and which systems were affected.
* **Response & Improvement** — recovering from an incident and improving security to prevent similar incidents.

## Visibility

Defenders need **visibility** into their environment to identify suspicious behaviour.

Examples include:

* Logs
* Network traffic
* Security alerts
* Repeated login attempts
* Unusual IP addresses

## Scope

A defender's **scope** is the systems and infrastructure they are responsible for protecting.

This can include:

* Employee devices
* Servers
* Applications
* Networks
* Users
* Data

### Key Takeaway

**Defenders need to know what they are protecting before they can protect it.**

A simple defensive security process is:

**Understand → Prevent → Detect → Mitigate → Analyse → Respond & Improve**


## The Defender Mindset

Defenders should understand how attackers might move through an environment.

Attackers may:

**Compromise one system → steal credentials → move to another system → reach sensitive data**

Defenders should therefore think about the whole environment as an **interconnected chain**.

## Key Defender Principles

* **Threat anticipation** — think about realistic ways an attacker could target the systems.
* **Attack awareness** — understand common attack stages and attack chains.
* **Risk prioritization** — focus on protecting high-value systems and targets first.
* **Continuous adaptation** — regularly improve defences as threats and vulnerabilities change.

## Layered Security

No single security tool can stop every attack. Defenders use multiple protections together, creating **defence in depth**.

| System           | Possible Risk                      | Example Defences                           |
| ---------------- | ---------------------------------- | ------------------------------------------ |
| Employee Devices | Malicious links or unsafe software | Antivirus, software updates                |
| Web Server       | Website attacks                    | Allow safe traffic, secure communication   |
| Mail Server      | Malicious emails/attachments       | Spam filters, attachment scanning          |
| Firewall         | Unauthorised access                | Firewall rules, block known threats        |
| Internet         | External attacks                   | Restrict inbound traffic, monitor activity |

## Key Takeaway

Defensive security is about **understanding threats, prioritising risk and applying multiple layers of protection**.

Defenders should constantly ask:

**"What could an attacker do next, and how can I stop them?"**

## Key Terminology

* **Blue Team** — cybersecurity defenders who protect systems and respond to threats.
* **Client Infrastructure** — an organisation's networks, servers, devices and applications that need protection.
* **Visibility** — the ability to monitor activity across systems and identify potential issues.
* **Threat** — a potential danger that could harm systems or data, such as malware or an attacker.
* **Prevention** — stopping threats before they can cause harm.
* **Detection** — identifying threats or suspicious activity.
* **Mitigation** — reducing or stopping the impact of a threat.
* **Risk** — the likelihood and potential impact of a threat causing harm.

## Career Opportunities

* **Security Operations Centre (SOC)** — monitors systems and investigates suspicious activity and security alerts.
* **Threat Intelligence** — researches threats, attackers and trends to help organisations prepare and defend against attacks.
* **Digital Forensics & Incident Response (DFIR)** — investigates security incidents, contains threats and helps restore affected systems.
